# Referans proje belgeleri

Bu belgeler U01–U07'nin hedeflediği düşünce ve tutarlılık düzeyini göstermek için yazılmış öğretim örnekleridir. Bir model değerlendirmesi veya ayrı oturumlarda kaydedilmiş prompt koşusu değildir. Tam ürün şartnamesi ve çalışır uygulama içermez.

Kendi çıktınızı şu sırayla karşılaştırın: vision → prd → design → tech-stack → roadmap → tasks → AGENTS/CLAUDE. Eksik dosyaları ve daha ayrıntılı veri sözleşmesini U05 promptuyla kendi projenizde üretin. Bu dizini uygulama kökü gibi başlatmayın; kendi boş çalışma dizininizi kullanın.

| Dosya | Gösterdiği karar |
|---|---|
| [vision.md](vision.md) | Problem, kullanıcı ve ilk kapsam |
| [prd.md](prd.md) | Kimlikli gereksinimler ve gözlenebilir kabul |
| [design.md](design.md) | Kullanıcı akışı ve hata durumları |
| [tech-stack.md](tech-stack.md) | Aday teknoloji ile doğrulanmış kurulumun ayrımı |
| [roadmap.md](roadmap.md) | Teslim sırası ve bitiş koşulu |
| [tasks.md](tasks.md) | İlk sürümün küçük işleri |
| [AGENTS.md](AGENTS.md) | Kodlama ajanı için yönerge örneği |
| [CLAUDE.md](CLAUDE.md) | Ortak yönergeye başvuran ürün girişi |
